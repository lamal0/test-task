# lamal&co

A responsive one-page product landing site + a small PHP/SQLite API for an
email waitlist, built for the test task in `TASK.md`.

## Requirements

- PHP 8+

Check whether PHP is already installed and which version:

```bash
php -v
```

If that command is not found, or reports a version below 8, install PHP 8+ from
the official downloads page: **https://www.php.net/downloads.php**

## Run it

From the project root:

```bash
php -S localhost:8000
```

Then open **http://localhost:8000/** in a browser
